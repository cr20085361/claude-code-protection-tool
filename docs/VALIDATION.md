## 本机更新前维护修复 (2026-10-20)

现场失败发生在 MSIX 安装之前：包内 Code 缓存目录缺失使守护报 `ProtectionError`，而维护准备先等待守护健康；后续完整缓存验收又先于旧引擎权限修复执行。回滚后的代理停止状态也阻止了组合维护入口。

修复后，已缓存官方载荷可离线生成候选并重新核验；同账号管理员暂停守护后重建缺失目录及门禁，先收紧未核准旧引擎的执行权限，再完整核验。仅维护准备允许不要求代理监听，核心文件、配置、固定出站和网卡仍须核验；正式安装仍要求完整防护就绪。
