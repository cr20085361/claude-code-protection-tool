Claude Pro 安全入口 — 使用说明

本说明适用于已经完成本机部署和防护核验的环境；首次部署请阅读 README.md 和 docs/DEPLOYMENT.md。

1. 双击桌面“Claude Pro（安全入口）”。检查通过后打开 Claude Desktop。
2. 首次登录由本人完成。Code 功能是否可用取决于账号权限。
3. 红色文字表示当前检查尚未通过，请按具体原因处理；版本信息或旧成功记录不代表当前防护就绪。
4. 已核准节点池会自动选择可用连接；新增节点需要重新导入和核验，不能只在共享代理中切换。
5. 更新前保存工作并完全退出 Claude Desktop 和本地 Code，再按入口提示下载、安装并维护。
6. 关闭安全入口窗口不会自动退出 Claude Desktop 或后台守护。

部署完成不代表真实 Code 会话、睡眠唤醒或长期运行已验收；仍需验证正常 Code 响应和本地文件读取。
