Claude Pro 安全入口 — 本机使用说明

1. 双击桌面“Claude Pro（安全入口）”。程序自动检查防护和后台守护，通过后打开 Claude Desktop。
2. 首次打开时，请本人登录 Claude 账号。Code 功能是否可用取决于账号权限。
3. 使用入口中的“检查”查看当前状态。若检查失败，请按状态提示处理，不要把仅有版本信息视为防护就绪。
4. “检查新版”查询官方版本；更新前完全退出 Claude Desktop 和本地 Code，再按入口提示下载、安装并维护。
5. 关闭安全入口窗口不会自动退出 Claude Desktop 或后台守护。

本机已为工具配置独立代理，保留现有 v2rayN 配置。
部署完成不代表真实 Code 会话、睡眠唤醒或长期运行已验收；首次登录后仍需验证正常 Code 响应和本地文件读取。
